# Product Requirements Document (PRD)

## Project: ZCAM Gallery Plus (macOS)

### Overview
ZCAM Gallery Plus is a macOS application designed to streamline the process of ingesting, organizing, and managing footage shot with Z CAM cameras tethered to a MacBook. The app aims to provide a fast, reliable, and user-friendly experience for filmmakers and content creators who need to quickly download, preview, sort, rename, and manage their footage as it is captured.

### Goals
- Enable automatic ingestion of footage from a Z CAM camera tethered to a MacBook.
- Provide robust file management: sorting, renaming, previewing, and deleting footage.
- Offer a seamless, intuitive user interface for rapid workflows.
- Ensure reliability and data integrity during file transfers.

### Core Features
1. **Auto-Ingest**
   - Detect when a Z CAM camera is connected via Ethernet.
   - Automatically download new shots as they are taken.
   - Support for background ingestion and progress indication.

2. **File Sorting & Organization**
   - Options to sort files by date, camera, scene, take, or custom rules.
   - Configurable destination folders and naming conventions.
   - Support for creating project-based or date-based folder structures.

3. **File Renaming**
   - Batch renaming tools with customizable patterns (e.g., project, date, take number).
   - Preview renaming results before applying changes.

4. **Previewing**
   - Quick preview of video and image files within the app.
   - Support for common file formats (e.g., MOV, MP4, JPEG, RAW) and framerates up to 50p.
   - Thumbnail and list views.

5. **Deleting**
   - Safe deletion of unwanted files from both the Mac and the camera.
   - Confirmation dialogs and undo functionality.

6. **User Preferences**
   - Configurable ingest locations, naming rules, and sorting options.
   - Option to enable/disable auto-ingest.
   - Dark/light mode support.

7. **Notifications & Feedback**
   - System notifications for ingest completion, errors, or conflicts.
   - Progress bars and status indicators.

### Non-Goals
- Editing or color grading footage.
- Cloud backup or remote sync (initial version).

### Technical Requirements
- macOS native app (future: currently browser-based via Tampermonkey script).
- Written in JavaScript (future: migrate to Electron or Swift for native experience).
- Must handle large files and concurrent transfers robustly.
- Should be extensible for future camera support and cloud features.

### User Stories
- As a filmmaker, I want my footage to be automatically downloaded as I shoot, so I don't have to manually transfer files.
- As an editor, I want to preview and sort my footage quickly, so I can start editing sooner.
- As a DIT, I want to rename and organize files according to my workflow, so everything is ready for post-production.
- As a user, I want to safely delete unwanted takes, so my storage stays clean.

### Success Metrics
- Time from shot to ingest completion.
- User error rate during file operations.
- User satisfaction with UI/UX.
- Reliability of file transfers (no data loss).

### Future Considerations
- Advanced metadata extraction and tagging.
- Rudimentary NLE with Premiere Pro compatibility.
